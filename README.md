# EEZYbot MK2 Robotic Arm Controller

Software for controlling the **EEZYbot MK2**, an open-source 3D-printed robotic arm.
This project provides three ways to operate the arm, from manual control to
fully automated playback.

## Features

- **Gamepad control**: Drive each joint of the arm in real time using a game
  controller, for smooth and intuitive manual operation.
- **Web control**: Operate the arm from any device on the same network through
  a browser-based interface, with no extra software to install.
- **Record and replay**: Record a sequence of movements performed manually, then
  let the arm repeat them automatically. Useful for repetitive tasks and demos.
